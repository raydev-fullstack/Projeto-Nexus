o que significa usar na <a> em palavras:
<strong>
<small>

strong e small não são “apenas estilo”; eles têm significado.
Em HTML, isso importa para acessibilidade, SEO e leitura por tecnologias assistivas.

o que significa usar list-style none na <ul> :

É uma propriedade do CSS usada para remover os marcadores padrão (como as bolinhas de listas não ordenadas ou os números de listas ordenadas) dos elementos de uma lista.


o que significa usar text-decoration: none no <a> :

propriedade do CSS usada para remover decorações de texto, como linhas de sublinhado, linhas no meio ou acima do texto.
